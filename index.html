Research demos · Yunwei Zhao, NYU

Privacy, turned into something a computer can check

Three tools that read a privacy policy the way a machine can: as rules with a precise meaning, whose promises can be tested and whose code can be audited.

⚖️

PolicyClaw

Does a privacy policy contradict itself? Compiles legal text into first-order rules and uses an SMT solver to find overlapping permissions and prohibitions.

Open demo
📜

Privacy as Code

Does a service keep its promises over time? Turns policy promises into clauses, then walks a story step by step to check every action and duty.

Open demo
🔍

PoliScope

Does the code keep the promises? Checks whether a code base actually upholds a policy statement, and points to the violating code.

Open demo

A five-minute walkthrough

Each page is self-contained. In order, the fastest tour is:

  1. PolicyClaw — pick the contradiction example and step through the six stages, from text to an SMT verdict.
  2. Privacy as Code — pick Spotify from the published policies and click Run to watch each step get allowed or refused.
  3. PoliScope — see the policy statement, the violating code, and the one-line fix that was merged upstream.
